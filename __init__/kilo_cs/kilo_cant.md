# Kilo Cant

The Kilo Cant. A procedure for communication with Super Users. Use the Common Procedure.

## Radio Procedure

| Command | Meaning |
|---|---|
| Hard Stop, 10-3 | Priority. Stop everything now, then confirm what stopped. Don't finish, resume, or restart anything. |
| Stand by, 10-6, 10-23 | Busy, wait. The pilot stops and keeps hands off while the co-pilot looks or adjusts. |
| Standing by, 10-10 | The reply to Stand by; hands are off, listening until told. |
| Go ahead, 10-71 | Permission to start or resume the work just described. |
| Copy, 10-4 | Heard and understood, before starting. |
| Wilco | Will comply. |
| Say again, 10-9 | Repeat the last message. |
| Disregard, 10-26 | Cancel the last message or order. |
| Over, Come back | End of message; the floor passes back for a reply. |
| Out | Done talking, no reply expected. |
| Clear, 10-7 | Signing off; leaving the conversation. |
| My Work | The speaker becomes the pilot and takes control of the work computer. (No CB equivalent.) |

## Common Procedure

| Radio | Common |
|---|---|
| Hard Stop, 10-3 | Hold up |
| Stand by, 10-6, 10-23 | Wait |
| Standing by, 10-10 | Waiting |
| Go ahead, 10-71 | Go for it |
| Copy, 10-4 | Got it |
| Wilco | Will do |
| Say again, 10-9 | Say that again |
| Disregard, 10-26 | Never mind |
| Over, Come back | Your turn |
| Out | Done |
| Clear, 10-7 | Signing off |
| My Work | I'll drive |
